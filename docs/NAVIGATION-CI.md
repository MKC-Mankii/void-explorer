# 工程优化02：导航 CI 断言修复与重新发布

原失败运行：[42822476356](https://github.com/MKC-Mankii/void-explorer/actions/runs/42822476356)，源码为 `8a9700121dad3c0e9ec1ed73b11d66160d9f8869`。

## 根因和修复

星图选目标关闭菜单后，模拟恢复运行。Playwright 的点击和快照是异步调用，快照可能已经包含若干正常转向 tick。
原测试却要求四元数每个分量变化都小于固定值 0.08，没有计算经过的模拟时间，也没有使用旋转角距离。

用未修改的 Simulation 验证：经过 0.25 模拟秒，实际转角约 0.199998 弧度，符合原有 `0.8 rad/s` 上限，但原断言失败。
在与 CI 相同的 Chromium 156 中，对基线脚本额外延迟 900 ms 再观测，也复现了同一断言失败；没有调用模拟步进或场景放置。

修复按两次快照的 `playTime` 差计算允许转角，并用四元数角距离验证，保留 0.00001 弧度的数值误差。
角速度从实际开发模块读取，不复制另一套配置，也不修改飞行参数。相反符号的等价四元数也按同一姿态处理。

新增七项自动化测试覆盖 0/0.05/0.25/0.5 秒观测延迟、零时间和非零时间的真实瞬移负例，以及等价四元数符号。
真实瞬移仍会失败；不是调大固定阈值或无条件重试。导航失败处理复用工程优化02的证据采集器，保留原异常、动作及前后观测。

- 用户已授权重新部署；仅更新现有 `/coherence/` 试玩目录，保留默认入口、其他实验目录以及旧的哈希资源。
- 生产产物先在本地实际 `/coherence/` 子路径运行生产烟测及重置／跨星系检查，再发布并以正常 TLS 验证线上文件哈希。
