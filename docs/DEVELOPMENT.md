# 首版交付记录

日期：2026-11-01。项目：MKC-Mankii/void-explorer。

## 项目理解

核心是能亲自抵达世界的太空旅行：从驾驶到大气下降、地表停留，再回到飞船继续探索。PC 键鼠操作、空间尺度感和连续体验优先。参考页面已成功访问，仅用于理解视觉及最终体验，没有把页面回顾的开发过程作为约束，也没有复制其代码或图像。

## 实现选择

TypeScript、Three.js / WebGL 2、Vite，采用静态站点架构。相较原生客户端，无安装步骤，能直接在桌面浏览器运行；当前功能不需要服务器，所有代码与必要资产均在仓库。

- `src/universe.ts`：种子 PRNG、连续三维噪声、星系与行星数据、地表高度和显示单位。
- `src/terrain.ts`：六面球体四叉树地形，按观察距离细分，最多 10 层；每块 12×12 网格，裙边遮盖不同细分层的边缘。共享高度函数求有限差分法线，避免分块光照接缝。
- `src/simulation.ts`：独立于 DOM / WebGL 的状态机；飞行、着陆、已着陆、步行、起飞。负责惯性、地面与恒星边界、防撞、星系切换、发现与存档验证。
- `src/visuals.ts`：程序化飞船和环境；自定义着色器使用与标准材质一致的对数深度；地表岩石和晶体使用实例化绘制。
- `src/main.ts`：渲染循环、镜头、键鼠、场景生命周期、持久化、画质与后期泛光。
- `src/ui.ts` / `src/style.css`：中文操作与探索反馈、星图、日志、驾驶遥测和菜单。
- `src/audio.ts`：用户操作后启用的 Web Audio 音效，无外部音频依赖。

世界使用压缩尺度：1 引擎单位显示为 10 m，行星半径约 7–15 km。这样可在一次短游戏中完成旅行，同时保留球面曲率和从轨道到地表的连续性。距离数值不是天文学真实尺度，重力值和温度是程序化环境资料，尚不参与完整物理模拟。当前是惯性辅助的科幻驾驶，不是牛顿轨道模拟。

主要可见行星与恒星都有实际世界位置。背景细星点是遥远星空的视觉场，不是逐个模拟的可跃迁目录；星图中的五个主星系均可进入，15 颗行星均为生成的实体地形。恒星不可着陆。跨星系为约 1.9 秒跃迁，星系内部则连续飞行；并非在有限坐标内模拟真实光年旅行。

## 实际完成

完整的驾驶→扫描→下降→着陆→离舱→步行→采样→返回飞船→起飞→下一目的地循环。具备自动寻找附近陆地的着陆程序、近地限速、深水步行限制、星体接近保护、探索积分、日志、本地存档、三档画质、鼠标灵敏度、音效开关、驾驶舱与摄影模式。

轨道扫描 +100，首次着陆 +150，地表采样 +250；每个行星每项只能获得一次。自动着陆不能在过远或速度过高时启动；若附近找不到陆地，需要换一个区域。界面给出具体反馈。

## 验证

- `npm test`：13 项测试通过，覆盖 15 个目的地的确定性 / 种子差异、跨球面方向连续高度、15 颗行星逐个着陆 / 采样 / 起飞、完整探索循环、地面接触、步行与登船距离、惯性与制动、防撞、恒星边界、距离约束、导航、存档恢复及损坏数据处理；另以射线实际命中三颗行星高地网格，验证其与碰撞地表误差低于 0.9 m。
- `npm run build`：TypeScript 严格检查及 Vite 生产打包通过。
- 云端 Chromium 154 / Linux / SwiftShader：15 项浏览器检查通过，报告见 `browser-report.json`。实际验证键盘推进与制动、轨道扫描、着陆后高度、离舱与采样、地表移动、鼠标锁定与旋转、Esc 释放和暂停、登船起飞、星图航向、星系跃迁、日志、画质与摄影、刷新恢复及 1280×720 HUD。
- 已查看实际轨道、下降、地表、驾驶舱及星图截图，修正了地形法线接缝、追踪镜头距离、着色器深度一致性、镜头低于地面和 Esc 暂停问题。
- 着陆和起飞测试使用生产逻辑的模拟时间推进以保持确定性，截图前同步镜头和地形；这不等于连续人工操控 13 秒实飞测试。
- 图形设备是云端软件光栅器，1440×900 中档画质只得到约 2–3 FPS，不能据此宣称游戏在实际 GPU 上流畅。尚未在 Windows、macOS、Safari、Firefox 或实体 GPU 上验证，仍需要实机兼容与性能测试。

## 当前边界

- 有限的 5 个星系、15 颗行星、4 类调色 / 地形主题，没有无限加载宇宙或自定义种子界面。
- 地形为自适应细分，极近处仍可能见到层级切换；表面岩石和晶体在探索者附近生成，远距离行走后会重新布置，不提供独立刚体碰撞。
- 大气散射、海洋、星环、恒星与驾驶舱均为风格化近似；无体积云、海浪游泳、真实日夜轨道、飞船动态阴影、损伤或完整驾驶舱内部模型。
- 采样可以在任意可步行地表完成，目前没有额外剧情、资源经济、遗迹谜题或生物群落，长期探索的内容密度仍有限。
- 无手机适配、原生客户端、多人、云端账号 / 云存档；浏览器清理站点数据会删除进度。
- 云端浏览器通过不代表支持矩阵已全部验收；未进行生产安全 / 无障碍专项审计。
